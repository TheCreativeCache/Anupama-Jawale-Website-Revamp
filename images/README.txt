COVER PHOTO
===========

The photo next to her name at the top of the home page is:   Cover.jpg

To change it, replace this file with a new photo that has exactly the same name.

Tips
- A portrait or square photo works best. Keep the face near the upper middle.
- Keep the file under about 500 KB so the page loads quickly.
- The name is case-sensitive on GitHub Pages: it must be "Cover.jpg", not "cover.jpg".
- If the file is missing, the site shows the initials "AJ" instead, so nothing looks broken.

The gallery photos live in the folder  images/gallery/  (see the README.txt there).
