GALLERY PHOTOS
==============

Put the photos for the cork board in this folder.

Easiest way
- Name them photo-01.jpg, photo-02.jpg, ... photo-11.jpg
  They appear on the board in that order.

Tips
- Landscape or portrait both work. On the board each photo is shown as a square crop;
  when a visitor clicks it, the full, uncropped photo opens.
- Shrink big phone or camera photos first. About 1600 pixels on the longest side and
  under 500 KB each keeps the page fast.
- File names are case-sensitive on GitHub Pages ("Photo-01.JPG" is not "photo-01.jpg").
- To add captions, use different file names, or add more photos, edit js/gallery-data.js.
